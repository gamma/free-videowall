A little help.

Check the USB playlist first:

  • playlist.m3u is in the USB root, encoded as UTF-8.
  • Each path matches the filename and folder exactly.
  • The Roku supports your USB format and media codecs.
  • For blends, generate .start.jpg and .end.jpg sidecars using the USB helper.
