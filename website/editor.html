USB PLAYLIST STUDIO

Playlist workshop

Your files. Your order. One simple playlist.

Paste filenames or an M3U, arrange your loop, then download playlist.m3u. Everything happens in your browser. No media uploads, no account, no cost.

01 / Bring your list

↓ Drop files or your USB root folder here

Subfolders are scanned. No media uploads. You can also drop a single M3U file.

If you drop a subfolder such as “videos” from the stick instead, uncheck this to keep “videos/…” in the path. The folder picker below always expects the USB root.

Applied automatically when you paste or edit. This text list and the entries below stay in sync. Drop more files or add an entry below to extend your playlist.

For example E: or /Volumes/USB. This prefix is removed. Check the result: the Roku needs paths relative to the stick, not your computer.
From Explorer or Finder

Windows: Select files (Ctrl+A), then use “Copy as path” from the context menu. Paste here with Ctrl+V. Normal Copy may only copy file references.

macOS: Select files (Cmd+A), press Option+Cmd+C to copy pathnames, then paste here with Cmd+V. Set the USB root above.

Drop the USB root folder here, or choose it below. Its outer name is removed; subfolders stay intact. Selecting or dropping individual media files imports names only — put those files in the USB root. Helper .start.jpg/.end.jpg files are skipped in filename lists.

Only names are read for media; M3U files are read as text. Selecting media adds entries; choosing an M3U replaces the list. Folder selection imports media names only, not existing M3U files.

02 / Make it yours

· Use ↑ / ↓ to reorder. Picture duration includes the incoming blend.

    Add another entry

    Append a video or picture by its path on the USB stick. You can use the same file more than once.

    Leave duration empty for the full video or a 10-second picture. Positive seconds set the picture duration or video limit. −1 plays a whole video.

    03 / Save to your stick

    Copy the downloaded file into the USB root. Your actual media files must be on the stick at the paths shown above. Re-import an M3U to keep editing. Nothing is saved on this site; download your work before closing.
