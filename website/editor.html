USB PLAYLIST STUDIO

Playlist workshop

Your files. Your order. One simple playlist.

Paste filenames or an M3U, arrange your loop, then download playlist.m3u. Everything happens in your browser. No media uploads, no account, no cost.

01 / Bring your list

For example E: or /Volumes/USB. This prefix is removed. Check the result: the Roku needs paths relative to the stick, not your computer.
From Explorer or Finder

Windows: Select files (Ctrl+A), then use “Copy as path” from the context menu. Paste here with Ctrl+V. Normal Copy may only copy file references.

macOS: Select files (Cmd+A), press Option+Cmd+C to copy pathnames, then paste here with Cmd+V. Set the USB root above.

For a folder hierarchy, choose the USB root folder below. Its outer name is removed; subfolders stay intact. Selecting individual media files or dropping them imports names only — put those files in the USB root. Helper .start.jpg/.end.jpg files are skipped in filename lists.

Only names are read for media; M3U files are read as text. Selecting media adds entries; choosing an M3U replaces the list. Folder selection imports media names only, not existing M3U files.

    VIDEO → PICTURE → VIDEO

    Give each clip a little breathing room.

    Yes: mix a video, a JPG/PNG interlude and another video. Set the picture to stay for 8 seconds, for example. The app already supports this, including looping back to the beginning. The picture is an ordinary playlist item, not an automatically generated video frame.

    A picture between videos does not by itself guarantee black-free transitions. A missing outgoing video end frame can still leave a gap when that video finishes. For the existing prepared-frame transition, generate video .start.jpg and .end.jpg files with the USB helper. Pictures use themselves as transition frames. The app blends still images; audio is not crossfaded. This editor does not generate those frame files.
