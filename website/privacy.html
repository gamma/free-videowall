The app

Free Videowall reads playlists, media and optional transition images from the USB drive connected to your Roku. The app does not collect analytics, show ads, require an account, upload files, fetch internet media or operate a backend. Local developer-console messages can include filenames, paths and playback errors. Roku’s operating system and services may process data separately under Roku’s privacy policy.

This website and GitHub Pages

This static website contains no analytics, advertising, tracking pixels, embedded third-party media, external fonts, contact forms or app-set cookies. Its files are served by GitHub Pages. GitHub logs and stores visitors’ IP addresses for security, even when they are not signed in. This is separate from the app’s local playback.

Serving the website and maintaining its security are legitimate interests under Article 6(1)(f) GDPR. GitHub’s privacy statement describes its processing, retention and international transfers; this project does not set GitHub’s log-retention period.

Playlist workshop

The playlist workshop processes filenames, folder paths and M3U content entirely in your browser. Only names and relative paths are used for videos and pictures; media contents are not read or uploaded. Selected M3U files are read locally as text. The preview uses placeholders. There is no persistent storage in the browser or on a project server. Changes not downloaded are lost when you close the page.
